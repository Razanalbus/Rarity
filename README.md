# Rarity Website Project

This repository contains the source code for the Rarity organization's website.

## Project Overview

The website provides information about Rarity, an ethical upcycled fashion organization, including:
*   **Home (`index.html`)**: Introduces Rarity's mission of transforming fast-fashion waste into ethical fashion, showcases key statistics, provides an overview of services (upcycling, fair labor, community outreach), and includes calls to action.
*   **About Us (`about.html`)**: Details the organization's mission and vision, introduces the core team members, explains the focus on supporting garment workers in Bangladesh, and displays impact through a photo gallery.
*   **Services (`services.html`)**: Elaborates on the core activities: Upcycling & Sustainability (process details), Fair Labor Practices (worker benefits), and Community Outreach (target areas and initiatives). Includes impact statistics and testimonials.
*   **Donate (`donate.html`)**: Explains the impact of donations, provides specific examples of how funds are used (fair wages, materials, training), includes a detailed donation form with various payment options, and suggests other ways to support (clothing donation, volunteering).
*   **Donation (`donation.html`)**: A simpler page containing a basic donation form.
*   **Contact (`contact.html`)**: Provides multiple ways to get in touch, including contact details (email, phone, address), social media links, a contact form, office hours, and information about service areas with an embedded map.

## Technologies Used

*   HTML
*   CSS (`styles.css`)
*   JavaScript (`script.js`)

## Getting Started

To view the website locally:
1.  Clone or download this repository.
2.  Open the `index.html` file in your web browser.

## Project Structure

*   `.html` files: Contain the structure and content of the different website pages.
*   `styles.css`: Contains all the styling rules for the website.
*   `script.js`: Contains JavaScript for interactive elements (like sliders or form validation, if implemented).
*   `images/`: Contains all the images used throughout the website.
